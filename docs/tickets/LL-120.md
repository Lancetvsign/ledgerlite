# LL-120 — An action on a document opened from the register keeps the way back

**Branch** `feat/ll-120-back-after-actions` · **Status** implemented · **Origin** "start LL-120" (2026-09-28); the ticket number was undefined in the repo and one offered follow-up remained, the known limitation of LL-117 · **Decision** ADR-040 amendment · **Migration** none

A document opened from the account register keeps its "← Back to Account Register" link after you act on it: finalize
or void an invoice or bill, void a payment or bill payment, post, correct, undo or share on a statement review, or
reverse a journal entry (the reversal entry you land on keeps the link too).

## §11 — End-of-ticket report

**Ticket:** LL-120 — keep `back` across actions on the screens a register row opens.
**Branch:** `feat/ll-120-back-after-actions`.
**Files changed:** `src/app/reports/back.ts` (`backFrom`), the forms of `invoices/[id]`, `bills/[id]`, `payments/[id]`,
`bill-payments/[id]`, `bank-import/[batchId]` (a hidden `BackField`), their actions (`invoices`, `bills`, `payments`,
`bill-payments`, `bank-import`: every redirect back to the same screen keeps `back`), `src/app/journal/[id]/page.tsx`
(the Reverse link carries it), `journal/[id]/reverse/page.tsx` (the "← Entry" link and the form), `journal/actions.ts`
(`reverseJournalEntryAction` keeps it), tests, docs.
**Migrations created:** none. **DB constraints added:** none.
**Tests added:** unit — `backFrom` keeps a valid address (normalised) and drops a missing, foreign, crafted or file value.
E2E — trial balance → register → invoice → Void: the voided invoice still leads back to the register (URL asserted),
which shows the void and still leads back to the trial balance.
**Test results:** lint ✓ / typecheck ✓ / unit ✓ / build ✓ (`npm run ci`); e2e on CI.
**Accounting implications:** none — navigation only.
**Security implications:** the carried value is re-validated by the same allowlist on the server (`backFrom` → `parseBack`)
before it is put in a redirect, so a crafted form field cannot redirect off-site.
**Decisions made that were not specified in the ticket:** the ticket number was undefined; it was taken to be the one
remaining follow-up. The statement review's link to the reconciliation screen (LL-111) is not a register destination and
does not carry `back`.
**Known limitations:** none known.
**Recommended follow-up:** none required.
