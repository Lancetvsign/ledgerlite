**Ticket:** LL-085 — per-account ledger detail with running balance and links to source documents.
**Files changed:** `src/server/reports/account-register.ts` (new: `getAccountRegister`), `index.ts`
(barrel); `src/app/reports/register/page.tsx` (new screen), `src/app/reports/page.tsx` (index entry);
`src/app/accounts/account-row.tsx` ("register" drill-down link); ADR-040; this ticket.
**Migrations created:** none. **DB constraints added:** none.
**Tests added:** `tests/integration/account-register.test.ts` — debit-normal register (opening from a
prior period, running balance, reversal netting, closing = trial balance, source/reversal fields);
credit-normal register (credit − debit, closing = trial balance); inclusive period ends and empty
period carrying the opening forward; drafts excluded (raw-SQL DRAFT insert); cross-company/unknown
→ null, outsider → `AuthorizationDenied`, inverted/invalid dates throw. `tests/e2e/reports.spec.ts` —
register via the reports hub: A/R after an invoice and a payment (rows, running balance, totals,
closing), source links to the invoice and payment, entry link to the journal, drill-down from the
Chart of Accounts.
**Test results:** lint ✓ / typecheck ✓ / unit ✓ / build ✓ (`npm run ci`); reports e2e ✓ locally;
integration on CI.
**Accounting implications:** none to the ledger — a read-only, derived report using the ADR-011
population and the normal-balance sign convention; its closing equals the trial balance.
**Security implications:** `report.view` on every call; a cross-company account id reads as not
found; the company comes from the server session, never the URL.
**Decisions made not specified in the ticket:** balance shown on the account's normal side (and said
so on screen); year-to-date default period like the statements; bills labelled "Bill" although their
source type is `EXPENSE`; inactive accounts pickable.
**Known limitations:** no CSV export; no multi-account GL view; credit memos / write-offs / vendor
credits link to the journal entry because they have no screen.
**Recommended follow-up:** drill-down links from the trial balance and financial statements.
