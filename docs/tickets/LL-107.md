## §11 — End-of-ticket report

**Ticket:** LL-107 — correct the amount of a STAGED line before it posts; keep the extracted figure; audit; freeze decided lines.
**Branch:** `feat/ll-107-amend-line-amount`.
**Files changed:** `src/db/schema/bank-import.ts` (`amended_from`), `src/db/schema/audit.ts` (`BANK_IMPORT_LINE_AMENDED`),
`drizzle/migrations/0044_amend_line_amount.sql` (+ snapshot/journal), `src/server/bank-import/index.ts` (`amendImportLine`),
`errors.ts` (`LINE_NOT_EDITABLE`), `src/validation/bank-import.ts` (`amendImportLineInput`), `src/app/bank-import/actions.ts`
(`amendImportLineAction`), `[batchId]/page.tsx` (per-row "Edit amount" bound to a form outside the review form; "corrected
from" badge; notices), tests, docs.
**Migrations created:** `0044_amend_line_amount.sql` — `ALTER TYPE audit_action ADD VALUE 'BANK_IMPORT_LINE_AMENDED'`;
`ALTER TABLE bank_import_lines ADD COLUMN amended_from numeric(19,4)` (nullable, no backfill); hand-appended trigger
`bank_import_lines_amount_frozen_when_decided` (BEFORE UPDATE OF amount: refuses a change when the line's status is not
STAGED, `LINE_NOT_STAGED`, restrict_violation). Expand-only; idempotent; applied to the dev branch only.
**DB constraints added:** the amount-freeze trigger.
**Tests added:** `tests/integration/bank-import-amend.test.ts` — amount corrected, extracted figure kept (and kept across a
second correction), audit before/after, equal figure → no-op without audit; duplicate hash follows the corrected figure; a
misread transfer finds its mirror once corrected; a draft survives; the ledger posts the corrected figure; POSTED and IGNORED
lines refused by the service and a raw UPDATE refused by the trigger; another batch's line → not found. Isolation attempt
for `amendImportLine`. Unit: the input schema. E2E: correct, refused zero, post, dashboard cash.
**Test results:** lint ✓ / typecheck ✓ / unit ✓ / build ✓ (`npm run ci`); bank-import e2e locally; integration on CI.
**Accounting implications:** the ledger only ever sees the corrected figure (a staged line has no ledger effect); once a line
has posted its statement figure can no longer change, so the reconciliation and the audit trail stay consistent.
**Security implications:** `journal.post` in the line's company; a foreign batch/line reads as not found; the audit row carries
amounts only.
**Decisions made that were not specified in the ticket:** thousands separators and spaces in the typed figure are forgiven;
the sign convention is the statement's (negative = money out) and is stated in the message; the date and description are
not editable in this ticket.
**Known limitations:** an ignored line cannot be corrected without un-ignoring it first (LL-089's Undo); no per-line history
view — the audit log holds it.
**Recommended follow-up:** date and description corrections through the same form if the owner wants them.
