# LL-035 — Manual Journal Entry UI


**Branch** `feat/ll-035-manual-journal-entry`

> Implement LL-035: manual journal entry for authorized ACCOUNTANT and ADMIN users.
>
> Fields: transaction date, posting date, reference/description, and journal lines of
> account / description / debit / credit.
>
> Display running Total Debit, Total Credit, and Difference. **These are advisory
> only.** Say so in a comment at the top of the component. `LedgerService` is
> authoritative, and the server revalidates everything regardless of what the client
> computed. Disabling Submit when obviously unbalanced is a courtesy, not a control.
>
> Compute UI totals with `decimal.js` from string values. Do not use `parseFloat` for a
> monetary total even in the UI — a display total that disagrees with the server total
> is a support ticket you do not want.
>
> Require `journal.create` and `journal.post`. Account autocomplete is scoped to the
> current company and excludes inactive accounts by default.
>
> After posting, show the immutable entry detail with no edit affordance anywhere.
>
> **E2E tests:** post a balanced entry; attempt an unbalanced entry and confirm the
> server rejects it even when the client is bypassed; attempt posting into a closed
> period; attempt posting without the capability; confirm no edit control exists on a
> posted entry; confirm account search cannot surface another company's accounts.
