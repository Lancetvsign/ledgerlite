# LL-112 — Correct a misread date or description on a staged import line

**Branch** `feat/ll-112-amend-date-description` · **Status** implemented · **Origin** owner's choice for LL-112 (2026-09-27), the follow-up LL-107 recommended · **Decision** ADR-046 amendment · **Migration** 0048

The row's "Edit line" form on a statement's review page now corrects the date and description as well as the
amount, before the line is decided. What the parser read is kept and shown ("corrected from …"); every correction
is audited; a decided line's amount, date and description are frozen by the database.
