# LL-114 — A failed re-analysis keeps the first pass instead of failing the upload

**Branch** `feat/ll-114-keep-first-pass` · **Status** implemented · **Origin** owner's choice for LL-114 (2026-09-27), the follow-up recorded by LL-113's review · **Decision** ADR-034 amendment · **Migration** none

When a statement's first reading does not match its printed totals, LedgerLite asks the AI once more (LL-109). If
that second call fails, the upload used to fail and the first reading was lost. Now the first reading is staged and
the review shows its gap, so the reviewer can correct it (LL-107/LL-112) instead of uploading again.
