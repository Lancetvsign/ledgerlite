# LL-110 — Correct a posted transaction: Reverse a manual entry, Undo a posted import line

**Branch** `feat/ll-110-correct-posted` · **Status** implemented · **Origin** owner question (2026-09-25): "Is there a way to edit a transaction once it is posted?"; "start LL-110" (the ticket number was undefined in the repo; taken to be this offered follow-up) · **Decision** ADR-044 amendment · **Migration** 0046

A posted entry is immutable (invariant 3, enforced by trigger); corrections are reversals. This ticket gives
the two common cases a path in the UI: **Reverse** a manual journal entry, and **Undo posting** of a
statement line (entry reversed, line back to review to be corrected and posted again). Voiding a payment now
also returns the statement line applied to it.

**Tests added:** integration `correct-posted.test.ts` — manual reversal through the button's service path; a statement posting
refused there; undo → entry REVERSED, line STAGED, audited, then amendable and re-postable, balances right; PERSONAL; a

**Test results:** lint ✓ / typecheck ✓ / unit ✓ / build ✓ (`npm run ci`); journal + bank-import e2e locally; integration on CI.
**Accounting implications:** none to the rules — every correction is a reversal through `reverseEntryCore`, dated in an open
period; nothing edits or deletes a posted entry. A reconciled posting is left alone so completed reconciliations stay true.
**Security implications:** `journal.post` for both paths; the manual reversal still refuses non-manual entries; a foreign batch
or line reads as not found; the refusal messages carried to the page are fixed service text, never statement content.
**Decisions made that were not specified in the ticket:** the reverse form lives on its own page so the entry page stays free
of inputs (the existing e2e's proof that nothing there is editable is kept as is); undoing the origin of a matched transfer
takes its mirror back with it; a reconciled posting is refused rather than un-cleared automatically.
**Known limitations:** an undo is dated the company's today (the original's period may be closed; the reversal lands in the
open one, ADR-007); the cardholder cannot undo a line another company took — the taker gives it back.
**Recommended follow-up:** a reversal-date choice on "Undo posting" if the owner wants corrections back-dated into an open period.
