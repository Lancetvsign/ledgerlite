## §11 — End-of-ticket report

**Ticket:** LL-101 — make "in transit" mean exactly a marked-and-not-yet-matched statement line, show it as its
own state, age it at the gate, and stop independent marks from diverging.
**Files changed:** `src/server/ledger/invariants.ts` (`findIntercompanyMismatches`: the mark-only single-sided
rule, date-bound partner lookup, `asOf`/`maxTransitDays` options, `stale:` rows; `DEFAULT_MAX_TRANSIT_DAYS`),
`src/server/reports/intercompany.ts` (`state`, `inTransitOldestDays`, the same rule, date-bound), the report page
(three badges, row `data-state`, age), `src/server/bank-import/intercompany.ts` (`findMirrorMark` — a mark auto-joins
the counterpart's open mark; one entry per line in `findIntercompanyCandidates`), `index.ts` (two lines at one
entry refused up front); docs.
**Migrations created:** none. **DB constraints added:** none.
**Tests added:** `tests/integration/intercompany-in-transit.test.ts` — unequal independent marks are in transit
(never mirrored) with amounts and age, fresh accepted / stale reported / `maxTransitDays: 0` fails the gate; a
group-bearing raw one-sided entry is a mismatch (rolled back); as of a date between the two statement dates →
in transit, then mirrored; two equal lines get different candidates, one submit cannot aim two lines at one entry
(nothing posts), the offered allocation posts both; a mark auto-joins the open mark in the window and opens its
own group outside it. Updated: LL-099 suite (independent marks now join one group; pending = in_transit),
GL-T029 (states), e2e (In transit before the match).
**Test results:** lint ✓ / typecheck ✓ / unit ✓ / build ✓ (`npm run ci`); bank-import + reports e2e ✓ locally;
integration + GL suite on CI.
**Accounting implications:** the mirror statement is now exact: any difference not explained by fresh marks is a
mismatch; stale marks fail the gate.
**Security implications:** none new (auto-link reads the counterpart's entries under the same visibility rule).
**Decisions made not specified in the ticket:** the age limit is 33 days by default and a parameter of the invariant
(the gate test uses 0 to prove it bites); `report.mirrored` stays strict (state === 'mirrored') for callers that
want a boolean.
**Known limitations:** an unmatched mark older than the limit must be un-marked (LL-100) or matched to pass the gate.
