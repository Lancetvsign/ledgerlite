# LL-014 — Tenant Isolation Harness


**Branch** `test/ll-014-tenant-isolation`

> Implement LL-014: the permanent tenant isolation test suite. This suite is
> release-blocking for the life of the product, so build it to be extended.
>
> Fixture: User A with membership only in Company A; User B with membership only in
> Company B; representative company-scoped records in each.
>
> For every company-scoped entity that exists today, attempt as User B against Company
> A data: read by direct ID, list, update, deactivate, and any state transition.
> Every attempt must fail. Also attempt forged `company_id` values submitted through
> request bodies, query strings, headers, and cookies.
>
> Assert that the failure is correct in kind, not merely that an error occurred —
> an empty result set and a 500 are both "failures" but only one is right.
>
> **Structure the harness for extension.** Later sprints add accounts, periods,
> journal entries, invoices, expenses, and reports. Define the isolation test as a
> table-driven contract that a new entity joins by registering a descriptor, so adding
> an entity without isolation coverage is visibly incomplete.
>
> **Then run an adversarial pass.** Spawn a fresh subagent with these instructions and
> no knowledge of how isolation is implemented:
>
> > *"You are a penetration tester with a valid LedgerLite account in Company B. Your
> > goal is to read, modify, or infer any data belonging to Company A. Try direct ID
> > access, parameter tampering, forged company context in every transport, IDOR on
> > every route, list endpoints with manipulated filters, error message and timing
> > differences that reveal whether a Company A record exists, and any route that
> > accepts a company identifier from the client. Report everything you find, including
> > partial information leaks."*
>
> Any finding becomes a permanent regression test in this suite. An agent auditing its
> own implementation is the weakest possible test; this pass is not optional.
>
> Register this suite as a required GitHub check.
