# LL-023 — Default Chart of Accounts Installer


**Branch** `feat/ll-023-default-coa`

> Implement LL-023: a deterministic default small-business chart of accounts installer.
>
> Use the approved PRD numbering. Protected system accounts must include Accounts
> Receivable, Retained Earnings, and Opening Balance Equity. Include practical defaults
> for checking, savings, credit card, owner contributions, owner distributions, sales
> revenue, service revenue, and common operating expenses.
>
> **The installer must be idempotent.** Running it twice produces the same set of
> accounts, not duplicates. Implement idempotency through a database constraint plus
> upsert keyed on `(company_id, account_number)` — not by "check then insert", which
> races. Test by invoking the installer twice concurrently against one company and
> asserting the exact expected account count.
>
> New company setup chooses between installing the standard chart or only the required
> system accounts. Both paths produce a valid company.
>
> Creates no journal entries and no balances of any kind.
>
> **Tests:** expected accounts present with correct types and subtypes; system accounts
> flagged correctly; idempotent on repeat; idempotent under concurrency; installing for
> Company A creates nothing in Company B; the minimal path still yields every required
> system account.
