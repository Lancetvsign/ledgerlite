# LL-001 — Repository Bootstrap, TypeScript, Lint, Agent Files


**Branch** `chore/ll-001-repository-bootstrap`

> Implement LL-001: initialize the LedgerLite repository.
>
> Create a production-quality Next.js App Router application with TypeScript, React,
> Tailwind CSS, and npm, using the current stable Next.js version supported by Vercel.
>
> **TypeScript** must be strict from the first commit. Enable `strict`,
> `noUncheckedIndexedAccess`, `noImplicitOverride`, `exactOptionalPropertyTypes`, and
> `verbatimModuleSyntax`. Turning any of these off later to make code compile is
> prohibited — record that rule in `/docs/ARCHITECTURE.md`. Configure path aliases and
> document them.
>
> **Directory structure**, documented in `/docs/ARCHITECTURE.md`:
> ```
> src/app/          Next.js routes
> src/components/   UI
> src/server/       domain services (LedgerService lives here)
> src/db/           schema, client, migrations
> src/lib/          shared utilities, decimal config, logging
> src/validation/   Zod schemas
> tests/unit/  tests/integration/  tests/e2e/  tests/fixtures/  tests/helpers/
> docs/
> ```
>
> **Lint.** Configure ESLint for Next.js + React + TypeScript. Favor correctness and
> security rules over stylistic ones — do not add hundreds of formatting rules that
> generate noise. Specifically enforce: no floating promises, no misused promises,
> no explicit `any` without an inline justification comment, no unused variables,
> exhaustive switch handling, and React hooks correctness. Resolve every warning the
> initial codebase produces rather than disabling the rule.
>
> **Agent files.** Create `AGENTS.md` containing the LedgerLite engineering contract
> (I will supply it — ask if it is not already present in the repo). Create `CLAUDE.md`
> that imports it with `@AGENTS.md` plus Claude Code specific guidance.
>
> **Guardrails.** Install `.claude/settings.json` with PreToolUse hooks and the
> `scripts/guard-bash.sh` / `scripts/guard-write.sh` scripts. Verify each hook actually
> blocks by testing it, and report the test output.
>
> Create `README.md`, `CHANGELOG.md`, `/docs` skeleton files, `.env.example` (names and
> explanations only, never values), `.nvmrc`, and an `engines` field pinning the Node
> version. Configure `.gitignore` for Node, Next.js, Vercel, env files, test output,
> coverage, and Playwright artifacts.
>
> Create `npm run typecheck` and `npm run ci` (lint → typecheck → unit → build).
>
> Landing page displays only: `LedgerLite` / `Development Environment`. No accounting
> functionality.
>
> **Acceptance:** `npm run dev` starts, `npm run ci` passes, no secrets committed,
> every hook demonstrably blocks its target command.
