# LL-117 — Entries and documents opened from the register link back to it

**Branch** `feat/ll-117-back-to-register` · **Status** implemented · **Origin** owner's choice for LL-117 (2026-09-28), the gap LL-115's review recorded · **Decision** ADR-040 amendment · **Migration** none

The last step of a drill-down now has a way back as well. A journal entry or source document opened from an account
register shows "← Back to Account Register" and returns to the register with its account and dates. From there the
register's own link continues up the chain, for example to the trial balance it was opened from.

## §11 — End-of-ticket report

register case pinned each row link's `href` to end at the id; it now asserts the exact `back` each carries.
**Test results:** lint ✓ / typecheck ✓ / unit ✓ / build ✓ (`npm run ci`); e2e on CI.
**Accounting implications:** none — navigation only.
**Security implications:** unchanged — `back` is validated by the same allowlist; every target re-authorizes.
**Decisions made that were not specified in the ticket:** the back link sits beside each page's existing header link
rather than replacing it; links onward from a journal entry (its reversal, its source) do not carry `back`.
