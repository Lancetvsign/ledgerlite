# LL-119 — The manual Reverse page proposes the entry's own date

**Branch** `feat/ll-119-reverse-date` · **Status** implemented · **Origin** owner's choice for LL-119 (2026-09-28), the gap LL-116's review recorded · **Decision** ADR-044 amendment · **Migration** none

Reversing a manual journal entry now proposes the entry's own date while its period is open, so the correction lands
in the period of the mistake. A note under the date says which date was proposed and why. If the period is closed,
or the entry is dated after today, today is proposed as before. This matches "Undo posting" on statement lines (LL-116).
