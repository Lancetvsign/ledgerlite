# LL-128 — Read statements with GPT-5.6 Sol

**Branch** `feat/ll-128-gpt-statement-model` · **Status** implemented · **Origin** the owner (2026-09-30): stop using the Anthropic model for parsing statements and use GPT-5.6 Sol · **Decision** ADR-050 · **Migration** none

Statement extraction now defaults to `openai/gpt-5.6-sol` through the Vercel AI Gateway. The model decides the route (a leftover Anthropic key no longer captures it), OpenAI reasoning models are sent low reasoning effort and non-strict JSON-schema mode, and Anthropic remains available by setting `BANK_IMPORT_MODEL`.
