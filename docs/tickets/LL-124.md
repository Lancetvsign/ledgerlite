# LL-124 — Undo all postings and delete a statement that imported wrongly

**Branch** `feat/ll-124-undo-all-and-delete` · **Status** implemented · **Origin** owner request (2026-09-29): "Can you make it so I can delete a downloaded statement if it won't import correctly"; "start LL-124" on the proposal (one-step undo-and-delete, and an easier-to-find delete) · **Decision** ADR-042 amendment · **Migration** none

A statement can already be deleted while nothing from it has posted (LL-087). Now a statement whose lines were
posted can be removed too: "Undo all postings and delete" reverses every posting from it, exactly as "Undo posting"
does line by line, and then deletes it. Lines that must be undone somewhere else, such as a deposit applied to an invoice
or an intercompany transfer, are listed first, and nothing changes until they're dealt with. "Delete…" now appears at
the top of the review and on every row of the imports list.
