## §11 — End-of-ticket report

**Ticket:** LL-090 — join links are the authorization; production sign-up only from a join link; a claim

**Tests added:** `tests/integration/members.test.ts` — claim by a holder with a different email; registering

**Test results:** lint ✓ / typecheck ✓ / unit ✓ / build ✓ (`npm run ci`); members + auth e2e ✓ locally;
integration and the migration on CI.
**Accounting implications:** none.
**Security implications:** closes Gate 6 H1 (email squatting), M2 (template slot via open sign-up) and M3
(stale invitation rewriting a role). The sign-up gate permits account creation only; membership is granted
solely by `claimInvitation`. Tokens are never stored or logged in clear.
**Decisions made not specified in the ticket:** the email on an invitation is a label (the join form
prefills it but a different address may claim); links are re-issuable and each issue replaces the last;
the join cookie lives 30 minutes; `describeInvitation` reveals the company name and role to a link holder.
**Known limitations:** no email delivery; legacy pending invitations must be revoked and re-created.
**Recommended follow-up:** none required; email delivery if a provider is ever configured.
